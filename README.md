# Portfolio

Personal portfolio website built with React + TypeScript + Tailwind CSS.

## Live Demo
[https://tiendat11.github.io/portfolio](https://tiendat11.github.io/portfolio)

## Tech Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS
- GitHub Pages (deploy)

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
